# Contributing

This repository publishes Recurse releases. Development happens elsewhere, so
pull requests here are closed automatically.

To report a bug or ask for a feature, [open an issue](https://github.com/ebetica/recurse/issues/new/choose)
and fill in the form. Agents work from these issues, so give exact details:
the output of `recurse --version`, your OS and browser, numbered steps to
reproduce, what you expected and what happened, and screenshots or logs with
any secrets removed.
